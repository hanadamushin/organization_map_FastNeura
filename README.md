# FastNeura Organization Map

役職・名前・所属先から組織図を作る、ブラウザ完結のアプリです。ビルド、外部ライブラリ、外部APIは不要です。

## 使い方

1. この非公開リポジトリをクローン、または「Code → Download ZIP」でダウンロードして展開します。
2. `index.html` をブラウザで開きます。
3. 役職と名前を入力し、必要なら登録済みメンバーから所属先（直属の上司・責任者）を選びます。
4. 所属先なしのメンバーは最上位に表示されます。最上位は複数登録できます。
5. 組織図のカードをクリックすると編集できます。

開発時は `python3 -m http.server 8000` で配信し、`http://localhost:8000` を開く方法もあります。サーバーはプロジェクトのディレクトリで起動してください。

## 機能

- メンバーの追加・編集・削除、階層の自動表示
- 自分や配下を所属先に指定する循環を防止
- 削除したメンバーの直属メンバーは、削除した人の所属先へ移動（最上位の削除なら最上位へ）
- 拡大・縮小・全体表示、キャンバスの縦横スクロール
- ブラウザの localStorage への自動保存
- JSONバックアップの保存・読み込み、形式・参照・循環の検証
- モバイル表示・キーボード操作対応

## 保存について

初期データは空です。名前などの実データはソースやGitHubへ送信しません。保存先はブラウザ内で、共同編集や端末間の同期はありません。プライベートブラウズ、ブラウザデータの削除、別ブラウザや別URLへの移動で、保存データを参照できなくなることがあります。`file://` の保存動作はブラウザに依存するため、安定した利用には固定の localhost URL で開く方法が適しています。

定期的に「JSONで保存」でバックアップしてください。読み込みは既存の組織図を置き換えます。別タブでデータが変更された場合は上書きを止めるため、画面を再読み込みしてください。メンバー上限は500名です。

このリポジトリは非公開ですが、将来Web公開する際のアクセス制御はホスティング先で別途必要です。本アプリに認証機能はありません。

## 構成・検証

- `index.html`: 画面
- `style.css`: レスポンシブデザイン・ツリー描画
- `model.js`: データ検証・階層操作（ブラウザ / Node.js共通）
- `app.js`: フォーム・保存・描画
- `model.test.js`: 循環防止・削除時の再所属・不正データ等のテスト

Node.js 18以上で `node --test model.test.js` を実行できます。
